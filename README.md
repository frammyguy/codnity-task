# Codnity React + MUI Demo (TS + Redux)


Vienkārša responsīva SPA ar 3 lapām, MUI komponentēm, Redux tumšās/gaišās tēmas slēdzi un satura ielādi no publiskiem API (Picsum, JSONPlaceholder).


## Tech stack
- React 18 + Vite + TypeScript
- Material UI v5
- React Router v6
- Redux Toolkit + React-Redux


## Palaišana
```bash
npm i
npm run dev
